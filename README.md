# Catálogo de métodos — Café de Ley × Expresiones

Sitio estático listo para subir a GitHub y publicar en Vercel. No requiere instalación ni proceso de compilación.

## Publicar

1. Usa el repositorio de GitHub conectado con `catalogo-metodos-expo-bogota.vercel.app`.
2. Sube **el contenido de esta carpeta** a la raíz del repositorio: `index.html`, `styles.css`, `main.js`, `products.js`, los archivos de imagen (incluido `og-catalogo-metodos.png`) y `.nojekyll`. Puedes subir también este `README.md`.
3. Espera a que Vercel publique la nueva versión y comprueba `https://catalogo-metodos-expo-bogota.vercel.app/og-catalogo-metodos.png`.

Las rutas de imágenes, CSS y JavaScript son relativas. Las fuentes usan Google Fonts y requieren conexión a internet; el sitio conserva fuentes de respaldo si no se cargan.

La imagen para compartir ya está en esta carpeta como `og-catalogo-metodos.png`. Las etiquetas Open Graph y Twitter de `index.html` apuntan a `https://catalogo-metodos-expo-bogota.vercel.app/`; cuando el repositorio conectado con Vercel publique estos archivos, la vista previa usará esa imagen.

Para ver el sitio antes de subirlo, abre `index.html` en un navegador.
