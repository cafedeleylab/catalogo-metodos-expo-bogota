# Catálogo de métodos — Café de Ley × Expresiones

Sitio estático listo para publicar en GitHub Pages. No requiere instalación ni proceso de compilación.

## Publicar como página principal del repositorio

1. Crea un repositorio en GitHub.
2. Sube **el contenido de esta carpeta** a la raíz del repositorio: `index.html`, `styles.css`, `main.js`, `products.js`, los archivos de imagen y `.nojekyll`. Puedes subir también este `README.md`.
3. En el repositorio, abre **Settings → Pages**. En **Build and deployment**, selecciona **Deploy from a branch**, la rama `main` y la carpeta `/(root)`. Guarda los cambios.
4. GitHub mostrará la URL de la página cuando termine la publicación.

Las rutas de imágenes, CSS y JavaScript son relativas, así que funcionan también en un repositorio de proyecto (`usuario.github.io/nombre-del-repositorio/`). Las fuentes usan Google Fonts y requieren conexión a internet; el sitio conserva fuentes de respaldo si no se cargan.

Para ver el sitio antes de subirlo, abre `index.html` en un navegador.
